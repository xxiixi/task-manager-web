# 点云渲染功能实现步骤

## 实现步骤

1. **安装 three.js 库**
   - 使用 `pnpm add three` 安装 three.js 3D 图形库

2. **创建 Canvas 容器**
   - 在 Vue 组件中使用 `<div ref="containerRef">` 作为 three.js 渲染容器

3. **实现 PCD 文件解析**
   - 读取 PCD 文件的 ASCII 格式数据
   - 解析头部信息获取点数量
   - 解析点坐标数据（x, y, z）
   - 计算边界框用于相机定位

4. **计算点云颜色**
   - 基于点的 Y 坐标（高度）和到中心的距离
   - 使用 HSV 颜色空间创建彩虹色渐变效果
   - 将 HSV 转换为 RGB 颜色值
   - 每个点都有独特的颜色

5. **初始化 three.js 场景**
   - 创建 Scene（场景）
   - 创建 PerspectiveCamera（透视相机）
   - 创建 WebGLRenderer（WebGL 渲染器）
   - 设置背景色并根据主题动态切换

6. **添加交互控制**
   - 使用 OrbitControls 实现鼠标旋转、缩放、平移
   - 启用阻尼效果使交互更流畅

7. **创建点云对象**
   - 使用 BufferGeometry 存储点位置和颜色数据
   - 使用 PointsMaterial 设置点的大小和颜色模式
   - 创建 Points 对象并添加到场景

8. **自动调整相机位置**
   - 计算点云的边界框和中心点
   - 根据点云大小自动调整相机位置
   - 设置控制器目标点为点云中心

9. **实现动画循环**
   - 使用 requestAnimationFrame 创建动画循环
   - 每帧更新控制器并渲染场景

10. **处理窗口大小变化**
    - 监听窗口 resize 事件
    - 更新相机宽高比和渲染器尺寸

11. **主题适配**
    - 监听主题变化，动态更新场景背景色
    - Dark 主题：深色背景（0x1e1e28）
    - Light 主题：浅色背景（0xf0f0f0）

12. **资源清理**
    - 组件卸载时清理动画帧
    - 释放渲染器资源
    - 移除 DOM 元素

## 技术要点

- 使用 three.js 的 BufferGeometry 和 PointsMaterial 实现高性能点云渲染
- 基于点的位置信息计算颜色，创建彩虹色渐变效果
- OrbitControls 提供流畅的交互体验
- 自动计算相机位置，确保点云完整显示
- 支持主题切换，背景色自动适配

## 颜色计算策略

- 使用 HSV 颜色空间创建平滑的颜色过渡
- 色相（Hue）：基于点的 Y 坐标和到中心的距离
- 饱和度（Saturation）：基于距离中心的距离
- 明度（Value）：基于点的 Y 坐标（高度）
